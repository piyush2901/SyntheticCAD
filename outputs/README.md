# Outputs

Generated outputs are written here during local runs and are not committed to
GitHub.

Typical output files include:

- `profile.json`
- `mapping_suggested.json`
- `mapping_guide.html`
- `synthetic_cad.csv`
- `validation_report.json`
- `executive_dashboard.html`
- `disclaimer.txt`

If a specific output should be shared with the team, place it in the shared cloud
storage folder or attach it to a project discussion instead of committing it.
