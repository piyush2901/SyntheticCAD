# SyntheticCAD Hosted Demo

This folder is the GitHub Pages publishing folder for the public workflow demo
and evidence dashboard. The workflow page can profile a CSV inside the browser,
and the evidence page shows a precomputed SDV run using fictitious victim data.

It intentionally contains only static demo artifacts and small fictitious
samples. Do not place agency data, private records, or large synthetic exports
in this folder.

Published entry point:

```text
index.html
```

Hosted workflow:

```text
demo.html
```
