# SyntheticCAD Demo Dashboard

This folder is the GitHub Pages publishing folder for the public demo dashboard.
The current page uses the fictitious victim dataset and contains aggregate
comparisons plus identifier-free source samples.

It intentionally contains only static demo artifacts. Do not place raw CAD
datasets, agency data, or large synthetic CSV exports in this folder.

Published entry point:

```text
index.html
```
