# Fictitious Demo Data

These 500-row CSV samples are fictitious and are included only for testing the
hosted SyntheticCAD workflow. They do not describe real people, victims,
patients, incidents, or hospital admissions.

- `victim_fictitious_sample.csv` demonstrates identity, demographic, offense,
  and event-date fields.
- `hospital_fictitious_sample.csv` demonstrates identity, admission, diagnosis,
  and length-of-stay fields.

The GitHub Pages demo profiles these files inside the browser. It loads a
precomputed SDV evidence dashboard instead of running synthesis on GitHub.
Use the Windows application for live local synthesis.
